# 9. Offline, notiser och resa

## Offline-paket

För tävlingar som användaren är anmäld till, favoritmarkerat eller aktivt följer ska appen kunna cachea ett **tävlingspaket**:

- Tävlingsgrunddata.
- PM/inbjudan och AI-sammanfattning.
- Min start och relevanta starttider i Min grupp.
- Arena, parkering och koordinater.
- Viktig kontaktinformation.
- Senast kända resultat/splits när relevant.
- Kartdata **endast i den omfattning licens/rättigheter medger lokal caching**.

## Notiser — opt-in per typ

- Anmälan stänger snart.
- PM publicerat.
- Starttid publicerad.
- Dags att åka.
- Live har startat.
- Resultat publicerat.
- Sverigelistan ändrad.
- Prediction tillgänglig.

## "När ska jag åka?"

Prioritet **Should**. Rekommenderad avresetid kan räknas från: starttid − önskad startmarginal − arena→start − tid på arena − parkering→arena − bilresa. Native maps-app används för faktisk navigation.
