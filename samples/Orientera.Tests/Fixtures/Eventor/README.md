# Eventor-fixturer

Svar i den form Eventors API dokumenterar
([OpenAPI-spec](https://github.com/orienteering-oss/eventor-api-openapi-spec)) — skrivna efter
specen, inte inspelade från skarpa svar, eftersom API-nyckeln kom först i och med SP-01.

Innehållet är modellerat på Gästrikland augusti 2026, samma verklighet som fake-datat, så att
normaliseringen testas mot data som ser ut som den den kommer att möta.

När en nyckel finns ska dessa filer bytas mot inspelade svar. Antagandena som då ska falla
eller bekräftas är listade i `samples/Orientera.Backend/README.md`.
